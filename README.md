\## 🧠 測驗在測什麼？



本測驗整合三大心理學研究系統，判定你目前的人生心理版本：



| 模組 | 理論來源 | 在測什麼 |

|-----|---------|---------|

| SST | Socioemotional Selectivity Theory | 你的人際策略是「擴張型」還是「精選型」 |

| AIRS | Authenticity Model | 你是否能在關係中做自己 |

| BAI | Somatic Marker / Boundary Autonomy | 你的界線是否已自動化 |

| EM | Meaning / Energy Priority | 你是否開始把意義與能量放在第一順位 |

| ID | Identity Integration | 你的人格整合完成度 |
